# Словарь показателей

Формулы зафиксированы в коде один раз, дашборд, отчёт и ИИ-помощник считают одинаково.
Меняется формула — меняется этот файл и `analytics/sql/002_metrika_views.sql`.

## Яндекс Метрика

| Показатель | Формула | Откуда |
|---|---|---|
| Визиты | `ym:s:visits` | `metrika_traffic.visits` |
| Посетители | `ym:s:users`, уникальные за период | `metrika_traffic.users` |
| Отказы, % | `ym:s:bounceRate`: визиты с одним просмотром короче 15 секунд | `metrika_traffic.bounce_rate` |
| Глубина просмотра | `ym:s:pageDepth`, страниц за визит | `metrika_traffic.page_depth` |
| Время на сайте | `ym:s:avgVisitDurationSeconds`, секунд | `metrika_traffic.avg_duration_sec` |
| Заявки с сайта | сумма достижений (`reaches`) целей из `METRIKA_LEAD_GOALS` | `metrika_kpi.leads` |
| Конверсия, % | заявки / визиты × 100 | `metrika_kpi.conversion_pct` |

Правила:

- **Месячные значения не складываются из дневных.** Посетители за месяц меньше суммы
  посетителей по дням, средние нельзя суммировать. Поэтому месяцы загружаются из Метрики
  отдельно (`grain = 'month'`), и для месячных показателей нужно брать именно их.
- **Источник визита** определяется моделью атрибуции `METRIKA_ATTRIBUTION`, по умолчанию
  `lastsign`, последний значимый переход. При сверке с интерфейсом Метрики выставьте в отчёте
  ту же атрибуцию.
- **Семплирование.** Данные запрашиваются с `accuracy=full`. Если Метрика всё равно отдала
  выборку, у строки стоит `sampled = true`.
- **Конверсия в интерфейсе Метрики** («конверсия по цели») считается как целевые визиты /
  визиты, а у нас — как заявки / визиты, поэтому цифры могут немного расходиться.

## Яндекс Вебмастер

| Показатель | Формула | Откуда |
|---|---|---|
| Показы | `TOTAL_SHOWS`, сумма по дням | `webmaster_search_daily.shows` |
| Клики | `TOTAL_CLICKS`, сумма по дням | `webmaster_search_daily.clicks` |
| CTR, % | клики / показы × 100 | `webmaster_search_monthly.ctr_pct` |
| Средняя позиция показа | средняя позиция дня, взвешенная показами | `webmaster_search_monthly.avg_show_position` |
| Средняя позиция клика | средняя позиция клика за день, взвешенная кликами | `webmaster_search_monthly.avg_click_position` |
| Показы по позициям | показы запроса за день попадают в диапазон 1 / 2–3 / 4–10 / 11–50 / 51+ по его средней позиции за этот день (с округлением) | `webmaster_position_buckets` |
| Спрос | `DEMAND`: сколько раз запрос задавали в Яндексе | `webmaster_query_daily.demand` |
| ИКС | индекс качества сайта | `webmaster_sqi` |

Правила:

- **Дни без показов и кликов не хранятся.** Нулями Вебмастер отвечает и за дни, по которым данных ещё нет,
  и за периоды, которых нет в его истории: у oldos.ru это июль 2025 – январь 2026 и половина марта 2026,
  хотя трафик из Яндекса по Метрике в это время был. В базе такие нули выглядели бы как полная потеря
  трафика из поиска. Настоящее падение до нуля будет видно по Метрике — пропадут визиты из поиска Яндекса.
  Полноту месяца показывают `days_with_data` / `days_in_month`, отставание по каждому потоку —
  `webmaster_freshness`.
- **Глубина истории в API разная.** Показы и клики по дням доступны с начала 2025 года. Популярные запросы
  отдаются только за последние месяцы (на 11.11.2026 — с июля 2026). Аналитика запросов отдаётся только
  за последние 14 дней с данными. История последних двух потоков копится в базе от запуска к запуску.
- **Показы по позициям приблизительны.** Точная позиция каждого показа в API недоступна, есть только
  средняя позиция запроса за день. Поэтому доли могут отличаться от тех, что показывает интерфейс Вебмастера.
- **Сверка с ручным отчётом.** Июль и август 2026 совпали: показы, клики, CTR, средние позиции
  (8,50 / 2,84 и 8,11 / 3,18 против 8,5 / 2,8 и 8,11 / 3,17 в отчёте).

## Яндекс Карты (счётчик Яндекс Бизнеса)

Яндекс Бизнес создаёт для карточки организации счётчик Метрики. Он грузится тем же сборщиком,
что и сайт (`METRIKA_MAPS_COUNTERS`). Для сети Олдос это счётчик 59047588 «Олдос».

| Показатель | Формула | Откуда |
|---|---|---|
| Визиты карточки | визиты счётчика карточки | `maps_monthly.card_visits` |
| Звонки | достижения целей «Клик на позвонить …» | `maps_monthly.calls` |
| Маршруты | «Построить маршрут …» | `maps_monthly.routes` |
| Переходы на сайт | «Переход на сайт …» | `maps_monthly.site` |
| Поездки по маршруту | «Движение по маршруту …» (цель появилась в январе 2026) | `maps_monthly.route_trips` |
| Мессенджеры и соцсети | «Переход в мессенджеры и социальные сети …» | `maps_monthly.messengers` |

Цели распознаются по началу названия (`analytics/sql/005_maps.sql`).

**Сверка с ручным отчётом за август 2026.** Звонки 104 против 106, переходы на сайт 199 против 202,
маршруты 160 против 172. Визиты карточки (2 804) меньше «переходов в профиль» в кабинете (3 876):
кабинет считает шире. Динамику счётчик передаёт верно (звонки +9,5% против +10%), поэтому подходит
для трендов и мониторинга. Для абсолютных цифр в отчёте — с пометкой об источнике.

## Вордстат

| Показатель | Формула | Откуда |
|---|---|---|
| Частотность фразы | запросы за месяц, где есть все слова фразы в любой форме, кроме минус-слов | `wordstat_monthly.count` |
| Брендовый спрос (B2B) | сумма фраз `[brand]` из `wordstat.toml`: «олдос ткани», «олдос фурнитура», «oldos ткани» и т. п. | `wordstat_groups_monthly` (`kind = 'brand'`) |
| Спрос категории | сумма фраз категории | `wordstat_groups_monthly` (`kind = 'category'`) |
| Спрос направления | сумма уникальных фраз его категорий | `wordstat_directions_monthly` |
| Сезон: пик · спад | месяцы с самой большой и самой маленькой средней долей в году, по полным годам с 2023 | дашборд |

Правила:

- **Бренд — только B2B.** «Олдос» — это ещё и детская одежда Олдос и писатель Олдос Хаксли, поэтому общие
  запросы («олдос», «олдос официальный сайт») в брендовый спрос не входят: только с «ткани», «фурнитура», «пвх».
- **Минус-слова убирают чужой спрос**: сканворды («5 букв»), биологию («соединительная ткань»), обои
  («флизелин»), стирку («гель для мембранных тканей»), готовые изделия («шуба из искусственного меха»).
- **Сумма фраз — оценка.** Оператор «или» API не поддерживает, фразы группы складываются; они подобраны
  с минус-словами так, чтобы почти не пересекаться, но небольшое двойное попадание возможно.
- **Задержка.** Месячные данные Вордстат публикует с опозданием: 12 ноября последний месяц — сентябрь.
  Дашборд показывает последний доступный месяц и пишет об этом.
- **Регион** зависит от выбранного сайта: oldos.ru — Россия (225), oldos.kz — Казахстан (159).

## Дашборд

- **Сравнение** — с прошлым месяцем (стрелка и процент) и с тем же месяцем год назад (только число):
  год назад у oldos.ru был провал счётчика, и процент вводил бы в заблуждение.
- **Неполные месяцы** (данные меньше чем за 90% дней) и текущий, ещё не закончившийся месяц
  на графиках по месяцам не показываются — на их месте пустое место на оси, под графиком подпись.
  Для неполного месяца Вебмастера в плитках нет сравнения с прошлым месяцем.
- **Контакты** — достижения целей Метрики с типом «телефон», «e-mail», «мессенджер», кроме целей-заявок.

## Открытые вопросы

Сверка с ручным отчётом за август 2026 (счётчик oldos.ru, 28874860), данные Метрики на 30.10.2026:

- **Август сходится полностью:** 23 061 визит, 17 967 посетителей, отказы 25,38%, визиты по всем каналам.
- **Июль в отчёте не совпадает с Метрикой:** в отчёте 12 779 визитов, 8 217 посетителей и 17,51% отказов,
  в Метрике 17 175, 12 604 и 15,01%. Поэтому рост за август составляет +34% визитов и +43% посетителей,
  а не +80,5% и +119%.
- **Какие цели считать заявкой** (`METRIKA_LEAD_GOALS`). 206 заявок из отчёта не получается ни из одной
  комбинации до трёх целей. Цифры за август: «Автоцель: отправил контактные данные» — 80,
  «Ecommerce: покупка» — 19, «Клик по номеру телефона» — 127, «Клик по email» — 16.
  Цель «Заявка - Все формы» срабатывает 3 120 раз в 1 722 визитах в месяц, это явно не только реальные заявки.
- **Конверсия 2,8% из отчёта** не выводится из 206 заявок / 23 061 визит (получается 0,9%).
- **Провал данных в июле–августе 2025:** 266 и 98 визитов в месяц, 16 дней без единого визита.
  Сравнение «год к году» для июля–сентября 2026 некорректно.
- **Вебмастер не обновляет данные с 8–10 октября 2026** (на 11.11.2026): поиск по 08.10, страницы в поиске
  по 07.10, обход роботом по 10.10. ИКС при этом свежий. У cns-corp.ru та же картина, а трафик из Яндекса
  по Метрике после 8 октября обычный, так что из поиска сайт не выпадал.
