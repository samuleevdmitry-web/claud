# Словарь показателей

Формулы зафиксированы в коде один раз, дашборд, отчёт и ИИ-помощник считают одинаково.
Меняется формула — меняется этот файл и `analytics/sql/002_metrika_views.sql`.

## Яндекс Метрика

| Показатель | Формула | Откуда |
|---|---|---|
| Визиты | `ym:s:visits` | `metrika_traffic.visits` |
| Посетители | `ym:s:users`, уникальные за период | `metrika_traffic.users` |
| Отказы, % | `ym:s:bounceRate`: визиты с одним просмотром короче 15 секунд | `metrika_traffic.bounce_rate` |
| Глубина просмотра | `ym:s:pageDepth`, страниц за визит | `metrika_traffic.page_depth` |
| Время на сайте | `ym:s:avgVisitDurationSeconds`, секунд | `metrika_traffic.avg_duration_sec` |
| Заявки с сайта | визиты, где сработала хоть одна цель из `METRIKA_LEAD_GOALS` (визит с двумя целями — одна заявка); отдельный запрос к Метрике с фильтром `EXISTS(ym:s:goal==…)` в каждом отчёте | `metrika_traffic.lead_visits` → `metrika_kpi.leads` |
| Конверсия, % | заявки / визиты × 100 | `metrika_kpi.conversion_pct` |

Правила:

- **Месячные значения не складываются из дневных.** Посетители за месяц меньше суммы
  посетителей по дням, средние нельзя суммировать. Поэтому месяцы загружаются из Метрики
  отдельно (`grain = 'month'`), и для месячных показателей нужно брать именно их.
- **Источник визита** определяется моделью атрибуции `METRIKA_ATTRIBUTION`, по умолчанию
  `lastsign`, последний значимый переход. При сверке с интерфейсом Метрики выставьте в отчёте
  ту же атрибуцию.
- **Семплирование.** Данные запрашиваются с `accuracy=full`. Если Метрика всё равно отдала
  выборку, у строки стоит `sampled = true`.
- **Конверсия** считается так же, как в Метрике: визиты с заявкой / визиты. Сколько раз сработала каждая цель
  (достижения), — в разделе «Заявки и цели»; сумма достижений больше числа заявок, потому что в одном визите
  может сработать несколько целей (клик по телефону и форма).
- **С фильтром «только люди»** визиты с заявкой собираются с двумя фильтрами сразу (роботность и цели):
  в месяцы с роботами отчёты по городам, страницам входа и ОС неполные (см. «Весь трафик и „только люди“»).

## Яндекс Вебмастер

| Показатель | Формула | Откуда |
|---|---|---|
| Показы | `TOTAL_SHOWS`, сумма по дням | `webmaster_search_daily.shows` |
| Клики | `TOTAL_CLICKS`, сумма по дням | `webmaster_search_daily.clicks` |
| CTR, % | клики / показы × 100 | `webmaster_search_monthly.ctr_pct` |
| Средняя позиция показа | средняя позиция дня, взвешенная показами | `webmaster_search_monthly.avg_show_position` |
| Средняя позиция клика | средняя позиция клика за день, взвешенная кликами | `webmaster_search_monthly.avg_click_position` |
| Показы по позициям | показы запроса за день попадают в диапазон 1 / 2–3 / 4–10 / 11–50 / 51+ по его средней позиции за этот день (с округлением) | `webmaster_position_buckets` |
| Спрос | `DEMAND`: сколько раз запрос задавали в Яндексе | `webmaster_query_daily.demand` |
| ИКС | индекс качества сайта | `webmaster_sqi` |

Правила:

- **Дни без показов и кликов не хранятся.** Нулями Вебмастер отвечает и за дни, по которым данных ещё нет,
  и за периоды, которых нет в его истории: у oldos.ru это июль 2025 – январь 2026 и половина марта 2026,
  хотя трафик из Яндекса по Метрике в это время был. В базе такие нули выглядели бы как полная потеря
  трафика из поиска. Настоящее падение до нуля будет видно по Метрике — пропадут визиты из поиска Яндекса.
  Полноту месяца показывают `days_with_data` / `days_in_month`, отставание по каждому потоку —
  `webmaster_freshness`.
- **Глубина истории в API разная.** Показы и клики по дням доступны с начала 2025 года. Популярные запросы
  отдаются только за последние месяцы (на 11.11.2026 — с июля 2026). Аналитика запросов отдаётся только
  за последние 14 дней с данными. История последних двух потоков копится в базе от запуска к запуску.
- **Показы по позициям приблизительны.** Точная позиция каждого показа в API недоступна, есть только
  средняя позиция запроса за день. Поэтому доли могут отличаться от тех, что показывает интерфейс Вебмастера.
- **Сверка с ручным отчётом.** Июль и август 2026 совпали: показы, клики, CTR, средние позиции
  (8,50 / 2,84 и 8,11 / 3,18 против 8,5 / 2,8 и 8,11 / 3,17 в отчёте).

## Яндекс Карты (счётчик Яндекс Бизнеса)

Яндекс Бизнес создаёт для карточки организации счётчик Метрики. Он грузится тем же сборщиком,
что и сайт (`METRIKA_MAPS_COUNTERS`). Для сети Олдос это счётчик 59047588 «Олдос».

| Показатель | Формула | Откуда |
|---|---|---|
| Визиты карточки | визиты счётчика карточки | `maps_monthly.card_visits` |
| Звонки | достижения целей «Клик на позвонить …» | `maps_monthly.calls` |
| Маршруты | «Построить маршрут …» | `maps_monthly.routes` |
| Переходы на сайт | «Переход на сайт …» | `maps_monthly.site` |
| Поездки по маршруту | «Движение по маршруту …» (цель появилась в январе 2026) | `maps_monthly.route_trips` |
| Мессенджеры и соцсети | «Переход в мессенджеры и социальные сети …» | `maps_monthly.messengers` |

Цели распознаются по началу названия (`analytics/sql/005_maps.sql`).

**Сверка с ручным отчётом за август 2026.** Звонки 104 против 106, переходы на сайт 199 против 202,
маршруты 160 против 172. Визиты карточки (2 804) меньше «переходов в профиль» в кабинете (3 876):
кабинет считает шире. Динамику счётчик передаёт верно (звонки +9,5% против +10%), поэтому подходит
для трендов и мониторинга. Для абсолютных цифр в отчёте — с пометкой об источнике.

## Вордстат

| Показатель | Формула | Откуда |
|---|---|---|
| Частотность фразы | запросы за месяц, где есть все слова фразы в любой форме, кроме минус-слов | `wordstat_monthly.count` |
| Брендовый спрос (B2B) | сумма фраз `[brand]` из `wordstat.toml`: «олдос ткани», «олдос фурнитура», «oldos ткани» и т. п. | `wordstat_groups_monthly` (`kind = 'brand'`) |
| Спрос категории | сумма фраз категории | `wordstat_groups_monthly` (`kind = 'category'`) |
| Спрос направления | сумма уникальных фраз его категорий | `wordstat_directions_monthly` |
| Сезон: пик · спад | месяцы с самой большой и самой маленькой средней долей в году, по полным годам с 2023 | дашборд |

Правила:

- **Бренд — только B2B.** «Олдос» — это ещё и детская одежда Олдос и писатель Олдос Хаксли, поэтому общие
  запросы («олдос», «олдос официальный сайт») в брендовый спрос не входят: только с «ткани», «фурнитура», «пвх».
- **Минус-слова убирают чужой спрос**: сканворды («5 букв»), биологию («соединительная ткань»), обои
  («флизелин»), стирку («гель для мембранных тканей»), готовые изделия («шуба из искусственного меха»).
- **Сумма фраз — оценка.** Оператор «или» API не поддерживает, фразы группы складываются; они подобраны
  с минус-словами так, чтобы почти не пересекаться, но небольшое двойное попадание возможно.
- **Задержка.** Месячные данные Вордстат публикует с опозданием: 12 ноября последний месяц — сентябрь.
  Дашборд показывает последний доступный месяц и пишет об этом.
- **Регион** зависит от выбранного сайта: oldos.ru — Россия (225), oldos.kz — Казахстан (159).

| Показатель | Формула | Откуда |
|---|---|---|
| Позиция запроса | позиция сайта в выдаче на день съёма; пусто — не найден в проверяемой части выдачи | `rabbit_positions.position` |
| В ТОП-3 / ТОП-10 | запросы с позицией ≤ 3 / ≤ 10 на день съёма | `rabbit_daily` |

## Весь трафик и «только люди»

Каждый отчёт Метрики собирается дважды: весь трафик и с фильтром `ym:s:isRobot=='No'` — то же, что
сегмент «Поведение → Роботность → Люди» в интерфейсе. В таблицах это колонка `audience` (`all` / `humans`),
в дашборде — переключатель. Для анализа динамики основной вариант — «только люди»: доля роботов
в 2026 году менялась от 78% до нуля, и весь трафик сравнивать между месяцами нельзя.

**С фильтром роботности Метрика отдаёт часть отчётов не целиком.** Проверено 13.11.2026 на октябре
oldos.ru (роботов в октябре нет, итоги с фильтром и без совпадают — 23 037 визитов): отчёт по городам
с фильтром отдаёт 77 строк из 462 (94% визитов), по страницам входа и ОС — заметно меньше строк,
а цели в этих отчётах теряются почти целиком (по городам — 0 строк, когда целей в запросе несколько).
Итоги (`totals`) при этом верные — пропадают строки. Поэтому сборщик ставит фильтр только там,
где роботы правда были: по сводке видно, в какие дни и месяцы визитов «только людей» столько же,
сколько всего, — за эти периоды «только люди» = весь трафик, строки берутся из него (точно и вдвое
меньше запросов к API). Где роботы были, остаётся отчёт с фильтром, а в дашборде у отчётов по городам,
страницам входа и ОС стоит пометка, что строки неполные.

## ПФ и риски

Раздел следит за накруткой поведенческих факторов (RabbitSeo) с двух сторон: заметна ли она Яндексу
и не прилетели ли уже санкции. Считается по последним данным после каждой загрузки (по понедельникам).

| Сигнал | Как считается | Тревога | Внимание |
|---|---|---|---|
| CTR запросов проекта на второй странице | клики / показы на позициях 11+ за последние 14 дней аналитики запросов Вебмастера: запросы проекта RabbitSeo против остальных запросов сайта | от 20% и в 5 раз выше остальных (от 10 показов) | вдвое выше остальных и от 5% |
| Кликов столько же, сколько показов | запросы с CTR от 80% на средней позиции 4 и ниже (от 3 показов) за 14 дней | от 8 запросов | от 3 |
| «Запрос + домен» | запросы, которые кончаются доменом сайта и не содержат бренда («ткань таслан oldos.ru») | от 5 запросов | от 1 |
| Доля Яндекса против Google | полная неделя (пн–вс) против медианы 4 прошлых полных недель (медиана — чтобы всплеск не раздул базу), по отчёту «Поисковые системы» по дням; меньше 100 визитов из двух поисковиков в неделю — не судим | доля −8 п.п., Яндекс −25%, Google не упал (−10% и меньше) | доля −5 п.п. или упали оба поисковика (−25%) |
| Массовая просадка позиций | последний съём RabbitSeo против съёма неделей раньше: выпали или упали на 10+ позиций | от 30% найденных (от 5 запросов) или ТОП-10 вдвое меньше | от 15% (от 3 запросов) |
| Отдача по частотным запросам | запросы проекта с частотностью от 100: в ТОП-10 сейчас; лучше и хуже, чем 3 недели назад | — | в ТОП-10 меньше трети и хуже не реже, чем лучше |

Итог: тревога по признакам санкций — «похоже на санкции»; иначе, если есть следы накрутки, — «санкций
пока не видно, но следы заметны»; иначе — «в норме». Тревоги и предупреждения попадают в «Обзор».

Почему так: живые люди почти не кликают по второй странице (у остальных запросов oldos.ru там около 1%)
и не дописывают домен к товарному запросу, а у малочастотного запроса почти каждый показ — сам бот.
Google — контрольная группа: накрутка в Яндексе на него не влияет, поэтому падение только Яндекса
отличает фильтр от сезона и проблем сайта.

**Разбор на 13.11.2026** (Вебмастер отдаёт запросы по 06.10, Метрика — по 12.11):

- Накрутка идёт с 28.09.2026 (первые клики по запросам проекта и запросам «… oldos.ru»), хотя
  отслеживание позиций в RabbitSeo — с 22.10.
- На позициях 11+ запросы проекта получили CTR 76,5% (26 кликов из 34 показов), остальные запросы
  сайта — 1,03%. По малочастотным запросам показы почти равны кликам: «ленточная фурнитура»,
  «ткань для тюбингов», «антистатические ткани для спецодежды» — 1 показ и 1 клик в день на 11–14 месте.
- 23 запроса вида «запрос проекта + oldos.ru»: 336 показов и 128 кликов за 28.09–06.10. В Метрике
  такие визиты роботами не помечены (0%), отказы 5%, 5,6 минуты, 4,5 страницы — бот ведёт себя
  «хорошо», поэтому «только люди» его не отсеивают.
- Признаков санкций пока нет: доля Яндекса в визитах из Яндекса и Google с августа держится на 45–48%,
  ТОП-10 RabbitSeo — 9–10 запросов весь период. Падение доли Яндекса (84% в начале 2025 → 57% в конце
  2025 → 46% с июля 2026) началось до этой накрутки.
- Отдачи нет: в ТОП-3 только запросы с частотностью 1–19 в месяц; из частотных «пвх ткани» (1 627)
  выпадает из ТОП-50, «ткань кордура» 39 → 49, «эластичная ткань» 34 → 36; 178 из 215 запросов
  проекта не найдены ни разу.

## Дашборд

- **Сравнение** — с прошлым месяцем (стрелка и процент) и с тем же месяцем год назад (только число):
  год назад у oldos.ru был провал счётчика, и процент вводил бы в заблуждение.
- **Неполные месяцы** (данные меньше чем за 90% дней) и текущий, ещё не закончившийся месяц
  на графиках по месяцам не показываются — на их месте пустое место на оси, под графиком подпись.
  Для неполного месяца Вебмастера в плитках нет сравнения с прошлым месяцем.
- **Контакты** — достижения целей Метрики с типом «телефон», «e-mail», «мессенджер», кроме целей-заявок.
  У oldos.ru клики по телефону и почте — заявки, поэтому в контактах остаются переходы в мессенджеры.

## Аналитические сводки

Сводка в каждом разделе собирается по правилам (`analytics/insights.py`) из тех же цифр, что в таблицах
раздела, — каждое утверждение можно проверить в таблице рядом. Сегменты меньше 3% визитов или 50 визитов
не комментируются, изменения меньше 10% не упоминаются.

| Правило | Вид |
|---|---|
| Визиты, заявки, отказы изменились больше чем на 10% (отказы — на 3 п.п.) | плюс / минус |
| Трафик вырос, а заявок меньше | вопрос |
| Доля роботов в месяце от 10% или резко упала | минус / плюс |
| Дни, когда визитов в 1,8 раза больше медианы месяца (подряд идущие — один всплеск) | вопрос |
| Сегмент отчёта дал наибольший рост или падение визитов | плюс / минус |
| Сегмент вырос втрое и больше — «откуда этот трафик?» | вопрос |
| Конверсия сегмента в 1,5 раза выше средней (от 3 заявок) | плюс |
| Сегмент от 5% визитов с конверсией ниже 30% средней или без заявок | минус |
| Отказы сегмента вдвое выше средних (или на 15 п.п.) | что проверить |
| Страны без продаж — от 3% визитов | вопрос и что проверить |
| Мобильные — от 30% визитов и конверсия вдвое ниже компьютеров | что проверить |
| Ночные визиты (0–6 ч) — от 15%; часы и выходные с заявками | что проверить / вопрос |
| Цели: изменение от 30%; цель-форма срабатывает в десятки раз чаще заявок | плюс / минус / что проверить |
| Поиск: показы, клики, CTR; запросы, поднявшиеся, упавшие и пропавшие; диагностика; устаревшие данные | все виды |
| Спрос: бренд и рынок к прошлому году; категории с ростом спроса от 15% | плюс / минус / вопрос |
| Карты: действия на 100 визитов карточки изменились на 1 и больше | плюс / минус / что проверить |

В отчётах по видам источников (поисковые системы, сайты, соцсети, UTM и т. п.) строка «Не определено» —
это визиты не из этого источника, она не показывается и не комментируется.

## Открытые вопросы

Сверка с ручным отчётом за август 2026 (счётчик oldos.ru, 28874860), данные Метрики на 30.10.2026:

- **Август сходится полностью:** 23 061 визит, 17 967 посетителей, отказы 25,38%, визиты по всем каналам.
- **Отчёт считал «только людей».** Июль в отчёте (12 779 визитов) — это визиты с фильтром
  «Роботность: люди» (12 784 в Метрике); весь трафик за июль — 17 175. С августа 2026 роботов в данных
  нет совсем (весь трафик = люди), а до этого их доля была огромной: 76% визитов в январе, 78% в марте,
  26% в июле. Поэтому рост августа к июлю +80% в отчёте верен для людей. Сравнивать месяцы до и после
  августа 2026 можно только в варианте «только люди».
