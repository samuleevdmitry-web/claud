# Разведка тендерных площадок (Этап 0)

Дата разведки: 01.10.2026.

## Как проводилась разведка и чего она не покрывает

Разведка выполнялась из облачного окружения разработки. **Сетевая политика этого окружения
блокирует все 10 площадок** (а также habr.com): прямые запросы к сайтам, `robots.txt` и
пользовательским соглашениям сделать не удалось. Все сведения ниже собраны через веб-поиск по
открытым источникам: справочные страницы самих площадок, их документацию, статьи и инструкции.

Пункты с пометкой **[проверить]** нужно подтвердить живым запросом с сервера с российским IP
до написания адаптера: точный формат пагинации, JSON-эндпоинты, наличие антибота, текст
`robots.txt` и пользовательского соглашения. Для каждого адаптера это будет первым шагом:
снять реальные ответы в фикстуры и только потом писать парсер.

Общие риски для всех площадок:

- **Геоблок.** Российские госресурсы (прежде всего ЕИС) блокируют зарубежные IP и «подозрительные»
  подсети из-за DDoS-атак. Приложение нужно запускать на сервере с российским IP.
- **Антибот-защита** (DDoS-Guard, Qrator, ServicePipe и аналоги) у крупных ЭТП встречается часто.
  Если площадка отдаёт JS-челлендж или капчу, адаптер **не обходит её**, а помечает площадку как
  «не проверена» и предлагает альтернативу (API, агрегатор, e-mail-рассылка).
- **robots.txt и соглашения** не прочитаны ни у одной площадки [проверить]. Если сбор запрещён
  явно, адаптер не делается, используется альтернатива.

## Итоги probe №1 (02.10.2026, компьютер пользователя)

- **ЕИС**: ошибка SSL — сайт подписан «Russian Trusted Root CA». Приложение скачивает
  сертификат с gu-st.ru в `data/certs/` и использует его только для своих запросов.
- **РТС-тендер, Tender.Pro**: страница антибота — автоматический сбор не делается.
- **Росэлторг**: серверный HTML, карточки `div.js-etp-procedure-grid-item`, пагинация `page`
  с 0, `rel="next"`. Даты публикации в выдаче нет — берутся первые 5 страниц, открытые лоты.
- **Фабрикант**: серверный HTML (Next.js), карточки `div[data-slot=card][data-id]`,
  `page_number`/`page_limit=40`; есть номер ЕИС, даты публикации и окончания приёма заявок.
- **ТЭК-Торг**: процедуры лежат в `__NEXT_DATA__` → `listingProcedures.data`
  (`registryNumber`, `title`, `organizerName`, `dates`, `sumPrice`, `okpd2`), но параметр
  `q` игнорируется — варианты проверяет `probe --round 2`.
- **ЭТП ГПБ, B2B-Center**: выдача приходит, но поисковая строка не применяется.
- **Сбербанк-АСТ**: редирект на главную; **OTC.ru**: SPA; **УГМК**: сертификат/DNS.

## Online Contract — публичный API (проверено 02.10.2026)

- `GET https://api.onlc.ru/purchases/v1/public/procedures` — без авторизации. Параметры
  выяснены по сообщениям API о неверных значениях:
  `filters[search]`, `filters[status]` (`1` — приём заявок открыт, на 02.10 — 354 закупки;
  `2` — закрытые), `filters[from]` (ISO-дата публикации), `filters[fz223]`,
  `filters[searchType]`, `sort` (`id`, `firstPublicationTender`, `startAt`, `stopAt`,
  `startPrice`, `torgDate`, `lastChange`, с `-` — по убыванию), `limit`, `offset`,
  `include=owner` (заказчик), `total=true`.
- `GET …/procedures/{id}?include=owner` и `GET …/procedures/{id}/positions` — карточка и
  позиции (наименование, количество, единица, цена, технические требования `ownerCondi`).
- Поиск идёт и по позициям (лотам). Даты публикации в ответе нет, есть дата торгов `date`.
- Карточка на сайте: `https://onlinecontract.ru/tenders/{id}` (223-ФЗ — `/zakupki-223fz/{id}`).
- У `api.onlc.ru` нет `robots.txt` (404); `robots.txt` сайта запрещает URL с `?` для обхода
  страниц сайта, API к этому не относится. Запросы идут с паузой 2–5 с.

## ГосПлан — тарифы и лимиты

- Тестовый сервер `v2test.gosplan.info`: без ключа, **10 запросов в минуту** (заголовки
  `x-ratelimit-limit-minute`, `retry-after`). Адаптер держит паузу 6,5–7,5 с.
- Продуктовый `v2.gosplan.info`: ключ в заголовке `apikey` (получить через Telegram-бот
  «Бот ГосПлан», пробный период 7 дней), базовый тариф 3 000 ₽/мес. Ключ задаётся
  в `.env` как `GOSPLAN_API_KEY`.

### ГосПлан API — проверено

- Спецификация OpenAPI: `https://swagger.gosplan.info/fz44/swagger.yaml`, `…/fz223/swagger.yaml` (v2.4.0).
- Серверы: тестовый `https://v2test.gosplan.info` (без ключа, базовые лимиты), продуктовый
  `https://v2.gosplan.info` (API-ключ, пробный период 7 дней через Telegram-бота, дальше платно).
  Условия: `https://gosplan.info/legal/api-usage/`.
- `GET /fz44/purchases` и `GET /fz223/purchases` поддерживают фильтры: `object_info`
  (ключевые слова в наименовании объекта закупки), `classifier` (ОКПД2/КТРУ или их группы,
  можно несколько), `published_after/before` (не раньше 2024-01-01), `updated_after/before`,
  `collecting_finished_after` (срок подачи), `stage`, `region`, `customer` (ИНН),
  `max_price_ge/le`. Пагинация `limit` (до 100) + `skip`.
- Детали закупки: `GET /fz44/purchases/{purchase_number}` и `/notification`.
- Пробный запрос `object_info=постельное белье санаторий` вернул актуальные закупки за
  01.10.2026. Поиск по `object_info` нечёткий (сортировка по релевантности), поэтому всю фильтрацию
  делает наш классификатор.

## 1. ЕИС (zakupki.gov.ru) — 44-ФЗ и 223-ФЗ

**Базовый источник для госсектора.**

| Параметр | Сведения |
|---|---|
| Публичный поиск | `https://zakupki.gov.ru/epz/order/extendedsearch/results.html` (параметры `searchString`, `morphology=on`, `fz44=on`, `fz223=on`, `pageNumber`, `recordsPerPage=_10…_50`, `af=on` и т.д.) |

| Официальный API | SOAP-сервис отдачи информации `https://int44.zakupki.gov.ru/eis-integration/services/getDocsLE2` (и `getDocsIP` для ИП/физлиц). Запросы по номеру закупки или по региону+дате+типу документа; ответ — ссылки на ZIP-архивы с XML. **Полнотекстового поиска нет**: API подходит для получения деталей и для выгрузки «всё за день по региону», но не для поиска по ключам |
| Токен | С 01.01.2025 нужен токен. Получение: зайти на `https://zakupki.gov.ru/pmd/auth/welcome` через Госуслуги (ЕСИА), зарегистрироваться как «потребитель машиночитаемых данных» (ФЛ, ИП или ЮЛ). Токен передаётся в заголовке `individualPerson_token`. В части источников указано, что для ЮЛ нужна КЭП [проверить] |
| FTP / открытые данные | FTP `ftp.zakupki.gov.ru` (логины `free/free`, `fz223free`) **закрыт с 01.01.2025**. Раздел «Открытые данные» `zakupki.gov.ru/epz/opendata` содержит только справочные наборы (РНП и т.п.), не извещения |
| Без авторизации | Поиск, карточки извещений, документы — да |
| Фильтры | Текст (с морфологией), закон, дата размещения/обновления, ОКПД2, КТРУ, регион, статус («Подача заявок»), НМЦК, заказчик |
| Пагинация | `pageNumber` + `recordsPerPage`; по известным данным выдача ограничена ~1000 результатов на запрос [проверить] — значит, нужно дробить окно по датам |
| Рендеринг | Серверный HTML, JS не нужен |
| Защита | Геоблок зарубежных IP; при частых запросах возможна временная блокировка IP [проверить]. Капчи на публичном поиске не встречалось в источниках [проверить] |
| robots.txt / соглашение | [проверить] |

**Предлагаемый способ:** поиск по RSS/HTML (по ключам и кодам ОКПД2) → детали из карточки HTML;
если будет токен — детали и изменения извещений брать из SOAP API (надёжнее, чем HTML).
