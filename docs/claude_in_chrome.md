# Проверка площадок через Claude in Chrome

Для площадок с капчей или антибот-защитой (сейчас это **Bidzaar**, **ТЭК-Торг**, **ЭТП УГМК**)
тендеры собирает расширение Claude in Chrome в вашем браузере, а приложение принимает их на
странице **«Импорт»**. Там они проходят ту же классификацию и дедупликацию, что и данные
автоматических адаптеров, а площадка отмечается проверенной. Если площадку давно не
проверяли, на главном экране появится предупреждение «Площадка не проверена».

## Подготовка (один раз)

1. Установите расширение Claude in Chrome и войдите в свой аккаунт Claude.
2. Зарегистрируйтесь на площадках и войдите в них в этом же Chrome: Bidzaar (bidzaar.com),
   ТЭК-Торг (tektorg.ru). Капчу и вход вводите сами — Claude их не проходит.
3. Запустите приложение (см. README) и откройте `http://127.0.0.1:8000/import` — там список
   поисковых запросов из файла ключей и формат данных.

## Как запускать (раз в 2 дня)

Откройте вкладку площадки, вызовите Claude in Chrome и вставьте промпт ниже, заменив
`<ПЛОЩАДКА>` и `<КОД>` (`bidzaar`, `tektorg`, `ugmk`).

```text
Ты собираешь тендеры для компании Velmorium (поставщик текстиля для гостиниц) на площадке <ПЛОЩАДКА>.

1. Открой в новой вкладке http://127.0.0.1:8000/import и скопируй список «Поисковые запросы».
2. На площадке <ПЛОЩАДКА> для каждого запроса выполни поиск закупок. Если есть фильтр
   «приём заявок / активные», включи его. Смотри только закупки, опубликованные за последние 3 дня
   (при первом запуске — за 30 дней).
3. Для каждой найденной закупки открой карточку и выпиши: номер на площадке, ссылку, название,
   заказчика, регион и место поставки, НМЦК, дату публикации, срок окончания подачи заявок,
   статус, позиции (наименование, количество, единица) и, если видно, коды ОКПД2.
   Ничего не придумывай: если поля нет — пропусти его.
4. Не фильтруй закупки по смыслу — это сделает приложение. Пропусти только явные дубликаты.
5. Если площадка показала капчу или просит войти — остановись и попроси меня пройти проверку,
   потом продолжай. Не пытайся обойти капчу.
6. Собери результат в JSON такого вида и вставь его в поле «JSON с результатами» на странице
   http://127.0.0.1:8000/import, затем нажми «Импортировать»:

{"source": "<КОД>", "complete": true, "searched_queries": [...запросы, которые ты прогнал...],
 "errors": [...что не получилось...],
 "tenders": [{"external_id": "...", "url": "...", "title": "...", "customer_name": "...",
   "region": "...", "delivery_place": "...", "nmck": 0, "published_at": "ГГГГ-ММ-ДД",
   "application_deadline": "ГГГГ-ММ-ДДTЧЧ:ММ", "status": "...",
   "positions": [{"name": "...", "qty": 0, "unit": "..."}]}]}

   Если прогнал не все запросы или где-то были ошибки — поставь "complete": false и перечисли
   проблемы в "errors".
7. В конце коротко напиши, сколько закупок нашёл и что ответило приложение.
```

## Если данных много

Страница «Импорт» принимает и файл `.json`. Можно попросить Claude сохранить JSON в файл и
загрузить его. Для интеграций есть `POST /api/import` (тот же формат) с заголовком
`X-Import-Token: <IMPORT_TOKEN из .env>` или с паролем приложения.

## Что считается «проверенной» площадкой

Импорт с `"complete": true` отмечает площадку как успешно проверенную на момент импорта.
С `"complete": false` проверка считается неудачной, и предупреждение останется на экране.
