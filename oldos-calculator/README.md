# Калькулятор OLDOS

Калькулятор стоимости постельного белья с двумя ролями:

- **Руководитель** — видит себестоимость и все наценки, редактирует справочники тканей, изделий и настройки.
- **Менеджер** — видит только продажную цену (+45%) и сумму партии.

Справочник хранится **на сервере в одном экземпляре**. Когда руководитель нажимает «Сохранить», у всех
открытых менеджерских страниц цены обновляются сами, без перезагрузки (в углу появляется
«Обновлено руководителем в 14:05»).

## Как устроено

```
server.js            сервер на Node.js без внешних зависимостей
public/index.html    страница калькулятора
data/data.json       справочник (создаётся автоматически при первом запуске)
```

- Логин и пароль проверяются на сервере, а не в браузере, поэтому их не видно в коде страницы.
- Менеджеру сервер отдаёт только названия, пошив, этикетки, наценку 45% и готовую стоимость ткани на позицию. Цен тканей за метр, норм расхода и остальных наценок у него в браузере нет.
- Изменять справочник может только руководитель, проверка тоже на сервере.
- Если справочник открыт у руководителя в двух окнах, сохранение из устаревшего окна не затрёт свежие данные: появится предупреждение.
- Изменения доставляются по Server-Sent Events (`/api/events`). Если связь пропала, страница переподключится сама и подтянет пропущенное.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
cd oldos-calculator
DIRECTOR_PASSWORD='пароль-руководителя' MANAGER_PASSWORD='пароль-менеджера' npm start
```

Откройте http://localhost:3000. Логины по умолчанию: `director` и `manager`.

В Windows (PowerShell):

```powershell
$env:DIRECTOR_PASSWORD='пароль-руководителя'; $env:MANAGER_PASSWORD='пароль-менеджера'; npm start
```

## Настройки (переменные окружения)

| Переменная | Обязательна | По умолчанию | Назначение |
|---|---|---|---|
| `DIRECTOR_PASSWORD` | да | — | пароль руководителя |
| `MANAGER_PASSWORD` | да | — | пароль менеджера |
| `DIRECTOR_LOGIN` | нет | `director` | логин руководителя |
| `MANAGER_LOGIN` | нет | `manager` | логин менеджера |
| `PORT` | нет | `3000` | порт сервера |
| `DATA_FILE` | нет | `data/data.json` | где хранить справочник |

Без паролей сервер не запустится: так в интернет не попадёт версия со стандартными паролями.

## Публикация в интернете

Подойдёт любой хостинг, где можно запустить Node.js и где **файлы сохраняются между перезапусками**.
На бесплатных тарифах облачных платформ диск часто временный: справочник будет пропадать при каждом
перезапуске. На таких платформах подключите постоянный диск (volume) и укажите путь к нему в `DATA_FILE`.

### Вариант: свой VPS (Ubuntu)

1. Установите Node.js 18+ и скопируйте папку `oldos-calculator` на сервер, например в `/opt/oldos-calculator`.
2. Создайте службу `/etc/systemd/system/oldos.service`:

   ```ini
   [Unit]
   Description=OLDOS calculator
   After=network.target

   [Service]
   WorkingDirectory=/opt/oldos-calculator
   ExecStart=/usr/bin/node server.js
   Environment=PORT=3000
   Environment=DIRECTOR_PASSWORD=пароль-руководителя
   Environment=MANAGER_PASSWORD=пароль-менеджера
   Restart=always
   User=www-data

   [Install]
   WantedBy=multi-user.target
   ```

   ```bash
   sudo chown -R www-data /opt/oldos-calculator
   sudo systemctl enable --now oldos
   ```

3. Включите HTTPS. Проще всего через [Caddy](https://caddyserver.com): он сам получает сертификат.
   Направьте домен на IP сервера и пропишите в `/etc/caddy/Caddyfile`:

   ```
   calc.ваш-домен.ru {
       reverse_proxy localhost:3000
   }
   ```

   После `sudo systemctl reload caddy` калькулятор будет доступен по ссылке `https://calc.ваш-домен.ru`.

**Без HTTPS не публикуйте:** пароли будут передаваться по сети открытым текстом.

## Полезно знать

- После перезапуска сервера всем нужно войти заново: сессии хранятся в памяти. Справочник при этом сохраняется.
- Резервная копия: «Настройки → Экспорт JSON» у руководителя или просто копия файла `data/data.json`.
  Вернуть данные можно через «Импорт JSON».
- После 10 неудачных попыток входа с одного адреса вход с него временно блокируется (до 15 минут).
