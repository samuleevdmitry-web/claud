# Калькулятор OLDOS

Калькулятор стоимости постельного белья с двумя ролями:

- **Руководитель** — видит себестоимость и все наценки, редактирует справочники тканей, изделий и настройки.
- **Менеджер** — видит только продажную цену (наценка «Для менеджера», по умолчанию 45%) и сумму партии.

Справочник хранится **на сервере в одном экземпляре**. Когда руководитель нажимает «Сохранить», открытые
страницы менеджеров обновляются сами в течение 10 секунд, без перезагрузки (в углу появляется
«Обновлено руководителем в 14:05»). Если вкладка была свёрнута, обновление происходит сразу при возврате на неё.

## Что в папке `site`

```
index.html   страница калькулятора
api.php      серверная часть: вход, выдача и сохранение справочника
config.php   логины и пароли (заполняете сами)
data/        справочник и служебные файлы; создаётся и защищается автоматически
```

Нужен обычный хостинг с PHP 7.4 или новее (на reg.ru подходит стандартный тариф с PHP 8.x). Базы данных не нужны.

## Установка на хостинг (ISPmanager, reg.ru)

1. **Подготовьте папку сайта.** В ISPmanager откройте «Менеджер файлов» → `www` → папку поддомена
   (например, `velmorium.oldos.tech`). Если там лежат заглушки хостинга (`index.php`, `index.html`),
   удалите их: иначе вместо калькулятора может открываться заглушка.
2. **Загрузите файлы** из папки `site`: `index.html`, `api.php`, `config.php`.
   Папку `data` можно не загружать: она создастся сама при первом входе.
   Удобно загрузить архив `oldos-calculator-site.zip` и распаковать его прямо в менеджере файлов.
3. **Задайте пароли.** Откройте `config.php` на редактирование, впишите пароли между кавычками и сохраните:

   ```php
   'director_password' => 'придумайте-пароль-руководителя',
   'manager_password'  => 'придумайте-пароль-менеджера',
   ```

   Пока пароли пустые, на странице входа будет сообщение «Сайт не настроен».
4. **Включите HTTPS.** У поддомена должен быть SSL-сертификат (зелёная галочка в списке сайтов) и включено
   перенаправление с HTTP на HTTPS в настройках сайта. Без HTTPS пароли передаются по сети открытым текстом.
5. **Откройте** `https://ваш-поддомен/` и войдите. Логины по умолчанию: `director` и `manager`.
6. **Проверьте защиту:** откройте `https://ваш-поддомен/data/oldos-data.php`.
   Должна быть пустая страница или ошибка 403/404, а не цены.

### Обновление калькулятора

Загружайте поверх только `index.html` и `api.php`. Файл `config.php` и папку `data` не трогайте:
в них ваши пароли и справочник.

## Как устроено

- Логин и пароль проверяются на сервере, а не в браузере, поэтому их не видно в коде страницы.
- Менеджеру сервер отдаёт только названия, пошив, этикетки, наценку для менеджера и готовую стоимость ткани
  на позицию. Цен тканей за метр, норм расхода и остальных наценок у него в браузере нет.
- Изменять справочник может только руководитель, проверка тоже на сервере.
- Если справочник открыт у руководителя в двух окнах, сохранение из устаревшего окна не затрёт свежие данные:
  появится предупреждение.
- Файлы в `data/` имеют расширение `.php` и начинаются со строки `exit`, поэтому даже по прямой ссылке
  их содержимое не отдаётся. Дополнительно папку закрывает `data/.htaccess`.
- Подписи «Цена +45%», «Сумма партии (+45%)» берут проценты из настроек и меняются вместе с наценками.
- Порядок изделий задаёт руководитель на вкладке «Изделия» (перетащить строку за ⠿ или стрелками ↑ ↓,
  затем «Сохранить»). В этом же порядке изделия показываются в калькуляторе у всех сотрудников.

## Полезно знать

- Вход запоминается на 7 дней.
- Резервная копия: «Настройки → Экспорт JSON» у руководителя или копия файла `data/oldos-data.php`.
  Вернуть данные можно через «Импорт JSON».
- После 10 неудачных попыток входа с одного адреса вход с него временно блокируется (до 15 минут).
- Сменить пароль — поправить `config.php`. Логины тоже можно поменять там.

## Проверка на своём компьютере

```bash
cd site
php -S localhost:8000
```

Перед запуском впишите пароли в `config.php`, затем откройте http://localhost:8000.
