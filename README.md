# Velmorium — мониторинг тендеров на гостиничный текстиль

Веб-приложение обходит тендерные площадки, находит закупки по ключевым словам из файла
`Velmorium_ключевые_слова_тендеры.xlsx` и раскладывает их по статусам
«Релевантный» / «На проверку» / «Отклонён». Приложение запускается на вашем компьютере:
российский IP нужен, чтобы площадки его пускали.

Готово: разведка площадок (`docs/sources.md`), ключевые слова и классификатор, адаптеры
**ЕИС** (напрямую и через ГосПлан API), **Online Contract**, **Росэлторг**, **Фабрикант**,
**ТЭК-Торг**, **Сбербанк-АСТ**, сохранение с дедупликацией, интерфейс (список, карточка, «Новые»,
площадки, журнал прогонов, уведомления, экспорт в Excel), планировщик (раз в 48 часов),
уведомления в Telegram/e-mail, приём данных от **Claude in Chrome** для площадок, которые
нельзя обходить автоматически (`docs/claude_in_chrome.md`).

## Доступ: администратор и менеджеры

- **Администратор** — логин и пароль из `.env` (`APP_USERNAME`, `APP_PASSWORD`), видит всё.
- **Менеджеры** — заводятся на странице **«Пользователи»** (логин, имя, e-mail, пароль). Видят
  только **Тендеры** (списки, карточки, оценка «✓ Да / ✗ Нет», свой статус, заметки, экспорт) и
  **Уведомления** о новых тендерах. Площадки, «Проверка», ключевые слова, импорт, удаление
  тендеров и пользователи им недоступны (адреса закрыты, а не только спрятаны из меню).
- Вход — через страницу `/login`, кнопка «Выйти» справа вверху. Смена пароля менеджера сразу
  закрывает его старый вход; снять галочку «доступ открыт» — закрыть доступ, не удаляя.
- После каждого прогона, если нашлись новые релевантные или «на проверку» тендеры, появляется
  уведомление «Новые тендеры» со списком (название, заказчик, срок, НМЦК). Его видят менеджеры
  в приложении (у каждого свой счётчик непрочитанных), получают письмом (если в `.env` заполнены
  `SMTP_*`, у менеджера указан e-mail и включены письма) и в Telegram-группе менеджеров
  (`TELEGRAM_MANAGERS_CHAT_ID`). Сообщения о сбоях площадок менеджерам не отправляются.
  `APP_BASE_URL` — адрес приложения для ссылок на тендеры в письмах.

**Как менеджерам открыть приложение.** По умолчанию оно доступно только на этом компьютере
(`127.0.0.1`). Чтобы открыть его для компьютеров в той же локальной сети (офис), добавьте в `.env`
`APP_BIND=0.0.0.0` и `APP_BASE_URL=http://<IP-этого-компьютера>:8000`, выполните
`docker compose up -d`, разрешите входящие подключения на порт 8000 в брандмауэре Windows.
Менеджеры открывают `http://<IP-этого-компьютера>:8000`. Компьютер с приложением должен быть
включён, когда менеджеры с ним работают.

**Доступ через интернет** — разместите приложение на VPS в России с доменом и HTTPS:
`docker compose --profile https up -d --build` поднимает прокси Caddy с бесплатным сертификатом.
Пошагово — `docs/deploy.md`. Не открывайте порт 8000 в интернет без HTTPS.

## Интерфейс

- **Тендеры** — вкладки «Новые», «Релевантные», «На проверку», «Отклонённые», «Все», «Удалённые»; фильтры
  по площадке, закону, региону, НМЦК, сроку подачи, категории, своему статусу; сортировка по
  сроку подачи (ближайшие сверху), score или дате публикации; срок меньше 3 дней выделен.
  В шапке — счётчики новых релевантных и «на проверку». Экспорт текущей выборки в Excel.
- **Оценка «✓ Да / ✗ Нет»** (подходит / не подходит) — в списке и в карточке, по одной или
  отмеченным пачкой. Оценка важнее автоматики: «Да» — во вкладке «Релевантные», «Нет» —
  в «Отклонённых»; повторное нажатие снимает оценку. Фильтр «Оценка» показывает неоценённые и
  случаи, где оценка расходится с автоматикой.
- **Удаление** — в карточке, отмеченных в списке или всех по текущим фильтрам. Удалённые
  лежат во вкладке «Удалённые» (их можно восстановить) и не возвращаются при следующих
  прогонах. «Сбросить фильтры» только очищает поля фильтра.
- **Проверка** — где автоматика ошиблась по вашим оценкам: лишние релевантные, пропущенные,
  маркеры/ключи/минус-слова, из-за которых это случилось, и подсказки слов для новых маркеров и
  минус-слов. Правка (удалить маркер, ослабить минус-слово, сделать ключ «Нужен маркер»,
  добавить минус-слово или маркер) сначала показывает, у каких тендеров изменится статус и
  сколько ошибок исправится, затем применяется как новая версия файла ключей и пересчитывает
  все тендеры. Действующий файл со всеми правками скачивается на странице «Ключевые слова».
- **Карточка** — все поля, ссылки на все площадки, позиции, подсветка найденных ключей,
  маркеров и минус-слов, свой статус и заметки, история изменений; если оценка расходится с
  автоматикой — готовые правки ключей для этого тендера.
- **Площадки** — состояние каждой, последний успешный прогон, ошибки, включение/выключение,
  «Запустить сейчас» с прогрессом, расписание. Если площадка не проверена (сбой, капча,
  блокировка, 0 результатов, хотя раньше были, давно не было импорта), на всех страницах
  висит красное предупреждение.
- **Уведомления** — итог каждого прогона и сбои площадок. Telegram и e-mail включаются
  переменными `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` и `SMTP_*` в `.env`.

## Расписание

Прогон раз в 48 часов (интервальный триггер, а не cron `*/2`, который сбивается на границе
месяца), первый запуск — в `RUN_START_TIME`. Интервал и время меняются на странице
«Площадки» (хранятся в БД) или в `.env`. Окно поиска — от последнего успешного прогона
площадки минус 2 дня; первый запуск — 30 дней, только с открытым приёмом заявок. Ранее
найденные тендеры с открытым приёмом заявок перепроверяются при каждом прогоне; изменение
срока подачи или извещения помечает тендер «обновлён».

## Запуск через Docker (рекомендуется)

Нужен Docker Desktop.

```bash
git clone <репозиторий> && cd claud
cp .env.example .env      # задайте APP_PASSWORD
docker compose up -d --build
```

Приложение: http://127.0.0.1:8000 (логин `velmorium`, пароль из `.env`). База — PostgreSQL в
контейнере `db`, данные сохраняются между перезапусками.

Команды внутри контейнера:

```bash
docker compose exec app python -m app.cli run              # прогон по всем площадкам сейчас
docker compose exec app python -m app.cli probe            # разведка площадок (см. ниже)
```

## Запуск без Docker

Нужен Python 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
uv sync
cp .env.example .env
# в .env: DATABASE_URL=sqlite:///./data/app.db
uv run uvicorn app.main:app            # http://127.0.0.1:8000
uv run python -m app.cli run           # прогон сейчас
```

При старте применяются миграции, а если в БД нет ключевых слов — импортируется файл из корня.

## Площадки

| Режим | Площадки |
|---|---|
| Автоматически (адаптер) | ЕИС напрямую, ЕИС через ГосПлан API, Online Contract, Росэлторг, Фабрикант, ТЭК-Торг, Сбербанк-АСТ |
| Claude in Chrome → «Импорт» | РТС-тендер, Tender.Pro, OTC.ru (антибот), Bidzaar (капча), ЭТП ГПБ, B2B-Center (robots.txt запрещает поиск роботам), ЭТП УГМК (адрес уточняется) |
| Не используется | ЭТП НИТ (nistp.ru) — торги по банкротству, закупок у поставщиков нет |

Автоматический сбор делается, только если robots.txt площадки не закрывает поиск для роботов;
паузы между запросами — не меньше `Crawl-delay` (у ЕИС — 60 с, поэтому её прогон идёт 2–4 часа).

**Разведка с вашего компьютера.** Адаптеры писались по ответам площадок, снятым командой:

```bash
python -m app.cli probe        # или: docker compose exec app python -m app.cli probe
```

Команда делает по 2–4 запроса на площадку с паузами, ничего не обходит и сохраняет ответы
в архив `data/probe/<дата>.zip`. Пришлите архив — по нему пишутся адаптеры и тесты.

Второй круг разведки (варианты параметров поиска и JS-файлы для SPA-площадок):
`python -m app.cli probe --round 2` → архив `data/probe/<дата>_r2.zip`; третий круг —
`--round 3` (модули поиска ЭТП ГПБ, B2B-Center, ТЭК-Торг, Сбербанк-АСТ) → `<дата>_r3.zip`.
Четвёртый — `--round 4`: по одному образцу ответа найденных API поиска → `<дата>_r4.zip`.
Пятый — `--round 5`: Сбербанк-АСТ, ЭТП НИТ (nistp.ru) и robots.txt ЕИС → `<дата>_r5.zip`.

**Сертификат Минцифры.** zakupki.gov.ru подписан «Russian Trusted Root CA». Приложение само
скачивает его с gu-st.ru в `data/certs/` и использует только для своих запросов (настройки
компьютера не меняются). Если скачать не удалось, сохраните сертификат в формате PEM вручную
как `data/certs/russian_trusted_root_ca.pem` (https://www.gosuslugi.ru/crt).

**ГосПлан.** Без ключа используется тестовый сервер (10 запросов в минуту — полный прогон идёт
долго). Ключ для продуктового сервера: Telegram-бот «Бот ГосПлан», 7 дней бесплатно, далее
3 000 ₽/мес. Укажите его в `.env` как `GOSPLAN_API_KEY`. Держите ГосПлан включённым и при
прямом адаптере ЕИС: тот по robots.txt делает 1 запрос в минуту и открывает карточки только у
перспективных закупок, а ГосПлан даёт позиции всех закупок ЕИС.

## Ключевые слова

Файл xlsx — единственный источник ключей. Новую версию загружают на странице
«Ключевые слова»: предпросмотр разбора масок с ошибками, затем применение; после применения
все сохранённые тендеры пересчитываются. Там же можно проверить классификацию на тексте.
Если действующая версия взята из файла в корне проекта (вручную ничего не загружали), то при
обновлении этого файла приложение при старте само применит новую версию.

Текущий файл (22.10.2026): ищем только отели и гостиницы. Санатории, пансионаты, базы отдыха,
общежития, больницы, школы, соцучреждения и государственные/муниципальные учреждения — минус-слова
(если в названии заказчика есть «гостиница/отель» — минус-слова из названия не учитываются).
Закупки без признаков заказчика идут «на проверку». Гигиенические наборы и косметика не ищутся.

Синтаксис масок: `*` — любое окончание, `|` — «или», скобки группируют варианты, слова подряд —
фраза (между словами не больше двух других слов), дефис или `/` внутри слова — части идут
строго подряд (`мини-отел*`, `спа-*`), `[её]` — один символ из набора. Сравнение без учёта
регистра, `ё = е`, кавычки и дефисы игнорируются, совпадение только по целым словам
(`отел*` не находит «отдел»). Основа на «согласный + к/ц» перед `*` ловит и форму с беглой
гласной: `подушк*` → «подушек» (отключается `MASK_FLEETING_VOWELS=false`).

Поисковые запросы к площадкам строятся из файла: все «Самодостаточные» ключи, ключи
«Нужен маркер» с приоритетом 1–2 и «Готовые запросы» типа «Без логики». Для ЕИС
дополнительно ищется по кодам ОКПД2/КТРУ (кроме кодов-исключений).

## Командная строка

```bash
python -m app.cli check-keywords [файл.xlsx] [--notes]   # разобрать файл ключей
python -m app.cli classify "Поставка полотенец" --customer "Санаторий «Дюны»"
python -m app.cli run [--source eis_gosplan] [--query "постельное белье"]
python -m app.cli probe [--source eis]
```

## Как добавить площадку

1. Снять реальные ответы (`probe` или вручную) и положить в `tests/fixtures/<код>/`.
2. Написать адаптер в `app/sources/<код>.py` с методами `search`, `fetch_details`,
   `healthcheck` (см. `app/sources/base.py`) и использовать `PoliteClient` — он держит паузы,
   повторяет при 429/5xx и распознаёт капчу и антибот.
3. Добавить площадку в `app/sources/registry.py` с `mode="api"` и фабрикой адаптера.
4. Написать тесты парсинга на фикстурах (`tests/test_sources.py`).
