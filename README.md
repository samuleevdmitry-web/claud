# Аналитика проекта

Сбор данных из Яндекс Метрики, Вебмастера, Яндекс Бизнеса и Битрикс24 в одну базу PostgreSQL.
На базе строится дашборд и работает ИИ-помощник (месячный отчёт и мониторинг).

Подключены **Яндекс Метрика** и **Яндекс Вебмастер**. Дальше — Битрикс24, Директ, Яндекс Бизнес.

## Доступ к Метрике и Вебмастеру

Нужен OAuth-токен **только на чтение**. Пароль от аккаунта не нужен.

1. **Технический аккаунт (рекомендуется).** Заведите отдельный Яндекс ID, например
   `analytics-bot@yandex.ru`. В Метрике: *Настройка счётчика → Доступ → Добавить пользователя*,
   логин технического аккаунта, права «Только просмотр». Если позже подключаем Вебмастер, там
   же: *Настройки → Права доступа*, делегировать права этому логину.
2. **Приложение.** Под техническим аккаунтом откройте https://oauth.yandex.ru/client/new:
   - название — любое, например «Дашборд аналитики»;
   - платформа — «Веб-сервисы», Redirect URI — `https://oauth.yandex.ru/verification_code`;
   - доступы: **Яндекс Метрика → получение статистики, чтение параметров своих и доверенных
     счётчиков** (`metrika:read`), **Яндекс Вебмастер** — `webmaster:hostinfo` и `webmaster:verify`.
     Второе право Вебмастера, несмотря на название, нужно и для чтения данных о сайте: без него API
     отдаёт только список сайтов.

   После создания скопируйте **ClientID**.
3. **Токен.** Под тем же техническим аккаунтом откройте
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>` и нажмите
   «Разрешить». На странице появится токен.
4. Положите токен в переменную окружения `YANDEX_OAUTH_TOKEN` (локально — в файл `.env`,
   на сервере — в его настройки). Не пересылайте токен в чатах и не коммитьте его в репозиторий.

   В облачной сессии Claude Code токен хранится как секрет окружения: прокси сам добавляет
   заголовок `Authorization: OAuth <токен>` к запросам на `api-metrika.yandex.net` и
   `api.webmaster.yandex.net`. Тогда `YANDEX_OAUTH_TOKEN` оставляют пустым, и сборщик
   отправляет запросы без своего заголовка.

По документации Вебмастера токен действует 6 месяцев, потом его нужно перевыпустить (шаг 3).

Отозвать доступ можно в любой момент: удалить технический аккаунт из доступов счётчика или
отозвать доступ приложения в настройках безопасности Яндекс ID.

## Запуск

```bash
cp .env.example .env          # заполнить YANDEX_OAUTH_TOKEN и METRIKA_COUNTER_ID
docker compose up -d db       # PostgreSQL
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
```

```bash
.venv/bin/python -m analytics check                       # доступы: счётчики, цели, сайты Вебмастера
.venv/bin/python -m analytics sync --since 2025-01-01     # первая загрузка истории всех источников
.venv/bin/python -m analytics sync                        # ежедневно: Метрика за 7 дней, Вебмастер за 30
```

Отдельные источники: `sync-metrika`, `sync-webmaster`. `check` выводит цели счётчика (ID целей-заявок
записываются в `METRIKA_LEAD_GOALS`) и сайты Вебмастера (нужный — в `WEBMASTER_HOST_ID`).

## Данные

| Объект | Что в нём |
|---|---|
| `metrika_traffic` | Визиты, посетители, отказы, глубина, время по дням и месяцам в срезах `total`, `source`, `utm`, `city`, `device` |
| `metrika_goal_stats` | Достижения целей в тех же срезах |
| `metrika_goals` | Цели счётчика и отметка «заявка» |
| `metrika_kpi` | Трафик + заявки + конверсия для любого среза |
| `metrika_monthly` | Месяц к прошлому месяцу и к тому же месяцу год назад |
| `webmaster_search_daily` | Показы, клики и средние позиции в поиске Яндекса по дням |
| `webmaster_queries_monthly` | Популярные запросы за месяц |
| `webmaster_query_daily` | Запросы по дням: показы, клики, позиция, спрос, главная страница |
| `webmaster_sqi`, `webmaster_pages_in_search`, `webmaster_crawl_daily` | ИКС, страницы в поиске, обход роботом |
| `webmaster_summary`, `webmaster_diagnostics` | Сводка сайта и проблемы из диагностики |
| `webmaster_search_monthly` | Поиск по месяцам с прошлым месяцем |
| `webmaster_position_buckets` | Показы по диапазонам позиций |
| `webmaster_freshness` | Насколько отстают данные Вебмастера |
| `sync_runs` | Журнал запусков сборщиков |

Формулы показателей — в [docs/metrics.md](docs/metrics.md).
