# Velmorium — мониторинг тендеров на гостиничный текстиль

Веб-приложение регулярно обходит тендерные площадки, находит закупки по ключевым словам из
файла `Velmorium_ключевые_слова_тендеры.xlsx` и раскладывает их по статусам
«Релевантный» / «На проверку» / «Отклонён».

Статус работ: этап 0 (разведка площадок, `docs/sources.md`) и этап 2 (каркас, БД, загрузка
xlsx, парсер масок, классификатор, тесты) готовы. Адаптеры площадок, список тендеров,
планировщик и Docker Compose — следующие этапы.

## Локальный запуск

```bash
uv sync                                  # Python 3.12, зависимости в .venv
cp .env.example .env                     # и поправьте DATABASE_URL на SQLite для локального запуска
.venv/bin/uvicorn app.main:app --reload  # http://127.0.0.1:8000
```

При старте применяются миграции Alembic, а если в БД ещё нет ключевых слов — импортируется
файл из корня проекта.

## Ключевые слова

Файл xlsx — единственный источник ключей. Новую версию загружают на странице
«Ключевые слова»: сначала предпросмотр разбора масок с ошибками, затем применение. После
применения все сохранённые тендеры пересчитываются. Там же можно проверить классификацию
на произвольном тексте.

Из командной строки:

```bash
.venv/bin/python -m app.cli check-keywords [файл.xlsx] [--notes]
.venv/bin/python -m app.cli classify "Поставка полотенец" --customer "Санаторий «Дюны»"
```

Синтаксис масок: `*` — любое окончание, `|` — «или», скобки группируют варианты, слова подряд —
фраза (между словами не больше двух других слов), дефис или `/` внутри слова — части идут
строго подряд (`мини-отел*`, `спа-*`), `[её]` — один символ из набора. Сравнение без учёта
регистра, `ё = е`, кавычки и дефисы игнорируются, совпадение только по целым словам
(`отел*` не находит «отдел»). Основа на «согласный + к/ц» перед `*` ловит и форму с беглой
гласной: `подушк*` → «подушек», `полотенц*` → «полотенец» (отключается
`MASK_FLEETING_VOWELS=false`).
