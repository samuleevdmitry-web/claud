Папка для выгрузок, которые сборщик загружает сам (раз в 15 минут проверяет, нет ли новых файлов).

Что сюда класть (Excel, .xlsx):
  1. Лиды с сайта в Б24 против заказов в 1С — файл с листами «Совпадения» и «Все лиды».
  2. Продажи с входящих звонков — файл с листами «Итог», «Все входящие лиды», «Заказы со звонков».
  3. Таблица семантики (Google Таблица → Файл → Скачать → Microsoft Excel) — листы «Яндекс», «Google»
     с колонками «Фраза», «Частотность год» и датами с позициями.

Названия файлов любые: сборщик узнаёт их по листам. Уже загруженный файл повторно не читается;
новая выгрузка за тот же месяц заменяет прежнюю. Файлы остаются только на этом компьютере.
Загрузить сразу, не дожидаясь проверки: docker compose exec collector python -m analytics import-crm
